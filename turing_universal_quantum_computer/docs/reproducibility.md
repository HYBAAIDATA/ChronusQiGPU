# Reproducibility

Start from the exact reviewed Git commit, not a floating branch. Record the commit
and verify a clean checkout. Use `uv sync --project turing_universal_quantum_computer
--locked --group research` from the monorepo root.

```bash
uv run --project turing_universal_quantum_computer --locked --group research \
  python turing_universal_quantum_computer/experiments/run_experiment.py
uv run --project turing_universal_quantum_computer --locked --group research \
  python turing_universal_quantum_computer/experiments/analyze_results.py \
  turing_universal_quantum_computer/results/local/ACTUAL_RUN_ID.json \
  --output turing_universal_quantum_computer/results/local/derived
```

Use the run ID actually printed by the runner. `results/local` is ignored; the CI
workflow uploads raw manifests and derived tables as run artifacts. Review and
archive selected immutable manifests under `results/manifests` only after checking
identity, data sensitivity, license and stated experimental scope. Keep large
raw datasets in an approved archive and record their checksums/URLs in manifests.

A manifest records configuration and lock hashes, observed source commit/state,
package/interpreter/platform identity, seed, job IDs, implementation and request
fingerprints, observable definition, exact coefficients, uncertainty semantics,
number of evaluations, execution reports/certificates/witnesses, elapsed times
and final status. Checksums are content checks, not a signature or proof of
scientific novelty. Development overrides are explicit and cannot turn ZIP or
dirty-tree runs into clean release evidence.

Manuscript tables are generated by `analyze_results.py`, never transcribed from
edited spreadsheets. The example cases have analytic reference solutions and
are package-validation evidence only. Broader benchmark claims require an
independently specified methodology, baselines, repetitions, resources and
appropriate uncertainty treatment.

Do not invent a tag, DOI, passed test, hardware identity or publication status.
Use the existing guarded release workflow for software publication. After the
approved release exists, archive the exact source/data artifacts and update
citation metadata with the real version, release date and persistent identifier.
