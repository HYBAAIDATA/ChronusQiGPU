## Purpose

EUCLID now has a governed learning layer that can be seeded without confusing seed material with learned capability. It records experience, preserves failures, generates curricula, consolidates memory, and advances claims only through explicit evidence stages.

The system permits investigation of unfamiliar computational regimes. Gödel and Turing results remain part of the mathematical environment and inform test design, but they are not treated as grounds for dismissing an untested regime. Conversely, being in uncharted territory does not permit evidence stages to be skipped.

## Implemented architecture

1. **Provenanced seed registry**
    - Every seed records its domain, statement, provenance, metadata, timestamp, and content hash.
    - Identical seeds are deduplicated without losing provenance.
2. **Append-only learning-event ledger**
    - Each event records observation, prediction, action, outcome, prediction error, uncertainty, causal attribution, modules, resource cost, and transfer status.
    - Events are predecessor-linked and hash-verified when state is restored.
3. **Seven-form memory**
    - Episodic
    - Semantic
    - Procedural
    - Causal
    - Counterfactual
    - Failure
    - Meta-memory
4. **Feedback integration**
    - The learning loop connects to confidence calibration, causal attribution, and bounded parameter updates.
5. **Active curriculum**
    - Tasks are prioritized from uncertainty, evidence gaps, disagreement, downstream importance, and seeded domains without experience.
6. **Evidence-gated claim ladder**
    - Seeded → hypothesized → internally reproduced → adversarially tested → externally compared → provisionally trusted.
    - Refuted claims are retained rather than erased.
7. **Consolidation and replay**
    - High-error and high-uncertainty events are prioritized for replay.
    - Consolidation creates a comparable snapshot without deleting the original events.
8. **Durable preservation**
    - State checkpoints use absolute paths, atomic replacement, file and directory synchronization, read-back verification, hash sidecars, and compressed generation history.
    - Evidence is mirrored into content-addressed, hash-chained vaults using lossless Merkle folding and deterministic gzip.
