Date: 2026-10-04. Reviewed baseline: a6afc8465358e25b680e3af98e70cae924ae17cc.
Status: source-level audit and implementation requirements; NOT runtime acceptance, hardware certification, or release closure.

## Scope and historical correction

Reconcile the July session directions and the CIaaS specification restated on 4 October with Chronus, Tensor and Turing. Keep one integrated repository and canonical owners. Do not reconstruct the July simplified pulvini.zip: that delivery replaced algorithms with simplified stand-ins, introduced truncating tensor behavior, and omitted deployment assets. An import smoke test was incorrectly described as broad verification. No synthetic-nonce experiment from that session establishes or refutes performance on real nonces.

Preserve structured Grover, phi structure, 32-face M32 geometry, exact supported algebra, variational computation, checkpoint recovery and reusable quantum mathematics. Separate Bitcoin-specific adapters from the enterprise-facing reusable path; do not delete the capability treasury's mining system. The enterprise path must not require headers, nonces, targets, wallets, pools or submission logic. Do not import a BTC corpus into HYBA_DATA.

The repository's July inventory reports 65 surfaces accounted for (7 adapter-added, 31 elevated, 2 present, 2 retired-with-reason, 23 superseded). This audit read its source report but did not execute its named tests. Coverage of that inventory does not establish coverage of the entire CIaaS specification.

## Ownership

- Chronus: physical device selection, compiled kernels, resident buffers, transfers, topology, launch limits and measured execution evidence.
- Tensor: backend-neutral operations, representations, metric/search contracts, precision/residual policy, routing and query-level accounting. Reuse Kellogg and the canonical PULVINI owners.
- Turing/VQC: supported quantum-formal algebra, structured Grover, quantum walks, variational programs, state-class admission, state witnesses and checkpoints. Consume Tensor/Chronus through explicit adapters rather than copying them.
- Lifecycle, durable storage, query/index and commercial policy are shared services, not three independent implementations.

## Confirmed source-level findings

1. HIGH: chronus/tensor_compute.py::execute_with_evidence calls _float32_array before validate_dispatch. Conversion/contiguity work therefore precedes the declared shape/addressing gate. Move validation to the earliest boundary and add spy tests showing invalid requests never convert or allocate. _declared_dims uses int conversion/equality, admitting booleans and integral floats; require genuine non-bool integer dimensions consistently across native/public paths.
2. HIGH: tensor/poincare11d.py::Poincare11DTransport.__post_init__ validates dtype/role/layout but not the factory's backend restrictions, a finite non-negative residual, or coherent lossy/residual metadata. Direct construction can label authoritative Float64 state as chronus-opencl or supply invalid residual evidence. Enforce the invariant in the public object, not only its factory. Arrays are mutable despite frozen dataclass metadata; establish ownership/copy or revalidation before dispatch.
3. HIGH: the enterprise reusable VQC boundary remains incomplete. phi_vqc.py accepts header/nonce training records and uint32 candidates, and package __init__.py eagerly exports mining-engine/target helpers. Preserve the existing mining adapter; add a generic feature/candidate/oracle interface and prove enterprise import/execution does not load mining, pool, wallet or BTC corpus paths.
4. MEDIUM: PhiGroverVQC's default graph is a 32-node Fibonacci-offset ring. Shape 32x32 and a name M32 do not establish dodecahedron/icosahedron face geometry. Preserve the ring as a separately named topology, bind canonical real M32 geometry explicitly and test face count, graph identity and mapping across all three planes.
5. MEDIUM: EnhancedGroverAlgorithm in july_compat redirects to standard bounded GroverSearch. This preserves a callable historical name, but does not by itself preserve the session's phi-structured oracle/manifold algorithm. Add provenance-labelled structured-search tests and matched-budget ablations on relevant real data; do not use synthetic nonce results as real-nonce performance evidence.
6. MEDIUM: chronus/README.md says the former active chronus namespace is being removed, then instructs importing chronus. This is internally contradictory and needs correction to the actual retired namespace.
7. Evidence gap: Tensor declares Grover/Hendrix and VQC manifold execution bridges unwired. Requirement capture is not implementation closure. Hardware availability, CI doubles, recorded historical totals and passing import smoke tests are distinct evidence classes.
