Preserve structured Grover, phi mathematics, real 32-face M32 geometry, supported exact algebra, quantum walks, variational programs and checkpoints. Implement the Turing-specific portions of C02/C04/C08-C10/C15/C18-C19 through existing owners. Consume Tensor for logical tensor/metric/routing contracts and Chronus for physical execution; do not build independent quantization, CUDA, GPUDirect, ABAC, index or autoscaling engines here.

Shared C01/C03/C05-C07/C11-C14/C16-C17 obligations apply only to compatible declared state/operation classes. Quantization and privacy noise cannot silently replace exact amplitudes; unsupported operations must be declined or explicitly labelled approximate. C20-C22 require one integrated rights/handoff/evidence record, not three contracts.

Priority gaps: phi_vqc.py remains a header/nonce uint32 ranker and root imports expose mining helpers. Retain that adapter in the capability treasury but add a generic feature/candidate/oracle enterprise interface with import-isolation tests. The default Fibonacci-offset ring is not proof of real M32 polyhedral adjacency. EnhancedGroverAlgorithm maps to bounded standard GroverSearch; separately establish the phi-structured manifold path and its evidence. No synthetic nonce result is a real-corpus result; do not copy BTC data into enterprise delivery.

10,000-qubit supported Clifford execution does not establish arbitrary universal circuits at that width. Run witnesses, finite-precision variational results, exact algebra and physical-device measurements remain distinct. This requirements addition does not claim algorithm, CI or hardware acceptance.
