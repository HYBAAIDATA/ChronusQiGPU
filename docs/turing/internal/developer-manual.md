## Shortest genuine workflow

From the repository root, use the installation instructions above. Run the existing package example in that environment. Documentation CI runs that file rather than maintaining a copied quickstart. This documentation increment does not claim it ran locally.

The native facade currently admits `exact_algebraic` and `stabilizer` targets. Its `auto` binding selects by dense budget, then stabilizer; it does not expose every registry backend. The canonical registry/planner contain `mps_exact`, whose support must not be removed from the product merely because the facade binding is narrower.

## Authentication and versioning

Local Python facade calls do not acquire service credentials. Do not publish the PYTHIA operator API as a TURING customer API. PR #97 is a separate library-level service control candidate, not an authenticated public HTTP service. Consumer compatibility, supported release windows and deployment authentication remain explicit owner decisions.
