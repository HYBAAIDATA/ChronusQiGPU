# What TURING delivers

## Purpose

TURING provides computational capability through admitted mathematical representations, explicit input constraints and inspectable execution evidence. Intended evaluators include enterprise analysts, application teams and scientific reviewers who need to distinguish a computed result from a claim about it.

## Capability purchased versus capability demonstrated

An enterprise evaluation should specify a problem family, admissible input domain, required outputs, capacity envelope and acceptance criteria. Access, support, governance and delivery obligations must be agreed separately; source-code presence is not a service entitlement.

The product does not require customers to operate physical quantum equipment for its mathematical software paths. It does not thereby establish physical-QPU execution, unrestricted wide-circuit computation or a measured speedup.

## From problem to evidence

1. State the problem and validate its input domain.
2. Admit a representation and configuration that cover the requested computation.
3. Execute, retaining the actual backend and execution classification.
4. Verify the result and its certificate/witness bindings.
5. Evaluate outcomes against independently agreed acceptance criteria.
