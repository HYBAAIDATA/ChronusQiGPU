# Chronus — computational geometry and the scientific frontier

**Scope:** implementation-grounded research programme. Mathematical identities, software execution, physical phenomena and production qualification are distinct. A software theorem cannot be upgraded into a physical constant by changing its terminology.

## Existing implementation reused

- `chronus.geodesic.discovery`: exact rational SPD constant-metric descent and candidate signature matching; it does **not** prove arbitrary smooth Riemannian metric optimisation.
- `chronus.geodesic.benchmarks`: exact finite candidate evaluation and equal-output comparison between complete sequential and H4 graph ordering, with independent oracle counts; both enumerate the complete domain and therefore **do not** establish O(log N) search.
- `chronus.storage.phyllotaxis`: Fibonacci convergent and Vogel/golden-angle **logical mapping**. The mathematical golden angle does not identify physical NAND addresses or an optimal memory-cell packing fraction.
- `chronus.storage.prime_product`: reversible bounded secondary *label* encoding, neither p-adic inverse transform nor disk quantisation.
- `chronus.storage.erasure`: **actual software single-erasure repair** using independently stored XOR parity and SHA-256 shard digests. Cassini's identity is **not** the correction algorithm. This mechanism is not yet persistent, distributed or physically fault-tolerant.
- `chronus.storage.durable`: THESEUS SQLite/WAL/full sync, content hashes, restart consistency and journal custody. It is a local database backed by an actual filesystem, not fabricated physical storage physics.
- `chronus.tensor.folded_state`: invertible M15 byte-pair transform, selective local-byte reconstruction; output bytes are not smaller than source bytes.
- `chronus.pulvini.interop`: numerical recursive fold with full retained kernels and validated reconstruction; working-set reduction need not imply net storage reduction.
- `packages/turing/src/turing/algorithms/clifford.py`: exact GF(2) stabilizer tableau mathematics. No physical qubits or measured decoherence are implied.
- `chronus.research.frontier`: executable Cassini/logical coordinate witness, exact SPD metric descent witness, complete bounded geometric finite-search comparison, and explicit unavailable physical claims.

## Explicit corrections to the supplied frontier draft

The draft returned a **target supplied by the caller** from its purported geodesic search and then labeled timing as logarithmic. It set unmeasured `energy_per_operation` to `0.0`, confused Voronoi point density with circle packing fraction, used a nonexistent `PhyllotaxisMesh.generate_points`, and assumed an `ExactFoldState` constructor absent from maintained code. None of these can be admitted as scientific evidence. The executable research wrappers replace these proxies with real exact checks and expressly limited claims.

## Demonstrated new bounded capability: direct PULVINI partial reconstruction

`chronus.tensor.pulvini_selective.unfold_partial_recursive` traverses only the requested indices through the exact protected fold chronology and the retained kernel entries. Unlike a full-unfold-and-slice compatibility path, it does not reconstruct unselected tensor values. Direct comparison against the original formally protected implementation passed sixteen focused real/complex unit cases and three public observed data workloads. Complexity for a bounded flat interval is O(depth x requested values); no O(1) claim or full-source checksum proof is inferred from a partial selection. This is numerical PULVINI output, not bit-exact M15 representation or net compression.
