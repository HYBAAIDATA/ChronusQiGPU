# System update documentation

This directory contains implementation notes and status documents. Treat them as source-review summaries, not as deployment attestations, test results, certifications, or release approval.

- [Current implementation assessment](current-state-assessment.md) — source-level scope and limitations.
- [Architecture and market assumptions](architecture-and-market.md) — implementation boundaries and unverified strategic statements.
- [Test evidence and limitations](test-evidence.md) — correction of historical test-count claims and evidence requirements.
- [Governance and acceptance controls](governance-and-acceptance.md) — process guidance; not proof that controls have been executed.

The controlling claim review is the [Chronusv2 claim audit](../claim-audit.md). Historical report material is indexed in [docs/reports](../reports/README.md).
