TURING retains one canonical implementation and import namespace. Typed contracts
specify program/parameter identity, admitted representation, executable artifact,
execution status, observable meaning and provenance. The convenience API delegates
to the existing production computation path rather than creating another engine.
Exact algebraic and tableau implementations support the package-validation cases.
The facade's finite optimizer exhausts a declared finite domain; it does not
establish arbitrary-angle synthesis or continuous-parameter convergence.
Correction/control integrations are extension contracts unless a concrete,
validated implementation is bound. Their absence is not a reason to reclassify
or block TURING's implemented exact mathematics.
