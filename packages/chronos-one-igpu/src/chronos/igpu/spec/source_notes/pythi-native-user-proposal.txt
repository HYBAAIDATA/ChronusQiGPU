In PYTHI, <code>rung</code> is a <b>structured coordinate</b> with a <b>mathematical address</b>.<br /><br />## III.2 The Address Function<br /><br />Every header maps to a rung. The mapping is deterministic, computable, and verifiable:<br /><br /><code>rung(header) = fold_to_rung(header_digest, target_bits)</code><br /><br />Where:<br /><br />- <code>header_digest</code> is the canonical digest of the header (SHA-256 or a Merkle root — this is the only place hashing appears, and it appears once, not <code>2^32</code> times)<br />- <code>fold_to_rung</code> is the Binet fold that maps a digest to a Lucas rung<br />- <code>target_bits</code> is the current difficulty<br /><br /><b>The rung is the nonce.</b> Not a random value to be searched. A computed position on the Lucas ladder.<br /><br />## III.3 The Security Model<br /><br />The PYTHI-native protocol is secure if and only if:<br /><br /><code>The mapping from header to rung is not invertible to a cheaper computation than the honest computation.</code><br /><br />This is the same security condition as any proof-of-work. The difference is the honest computation:<br /><br />- <b>Bitcoin:</b> honest = enumerate nonces until a valid hash is found<br />- <b>PYTHI:</b> honest = compute the rung from the header<br /><br />If the fold is a cryptographic permutation (which it is — Binet fold is invertible and its inverse is the unfold), and the header digest is collision-resistant (SHA-256 is), then <b>the computed rung is the unique valid rung for the header</b>.<br /><br /><b>The honest computation is the only computation.</b> There is no cheaper path. There is no cheaper path because there is no search.<br /><br />---<br /><br /># PART IV — THE MACHINE<br /><br />## IV.1 The Datapath<br /><br /><code>                ┌──────────────────────────────────────┐                 │           PYTHI DATAPATH             │                 └──────────────────────────────────────┘                                   │         ┌─────────────────────────┼─────────────────────────┐         │                         │                         │         ▼                         ▼                         ▼ ┌───────────────┐        ┌───────────────┐        ┌───────────────┐ │  Stage 1      │        │  Stage 2      │        │  Stage 3      │ │  DIGEST       │───────▶│  BINET FOLD   │───────▶│  LUCAS        │ │  SHA-256      │        │  φ-embedding  │        │  L_rung       │ │  (once)       │        │  matrix form  │        │  exact        │ └───────────────┘        └───────────────┘        └───────────────┘                                                         │                                                         ▼ ┌───────────────┐        ┌───────────────┐        ┌───────────────┐ │  Stage 6      │◀───────│  Stage 5      │◀───────│  Stage 4      │ │  CERTIFICATE  │        │  PRIME LOOKUP │        │  CASSINI      │ │  bind all     │        │  ROM          │        │  comparator   │ └───────────────┘        └───────────────┘        └───────────────┘         │         ▼ ┌───────────────┐ │  SHARE        │ │  rung, value, │ │  address,     │ │  proof,       │ │  certificate  │ └───────────────┘</code><b>Six stages.
