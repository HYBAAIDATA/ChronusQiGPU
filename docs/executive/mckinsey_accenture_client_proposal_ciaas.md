## Evidence-based status

Chronusv2 is a software prototype. The source includes selected exact-math reference workloads, a service/API, local persistence, experimental adapters, and demonstration flows. The default execution path is CPU reference code. Source presence does not establish a production service or customer deployment.

The current repository review does not substantiate claims of instant enterprise onboarding, hundreds of live tenants, production SLAs, a private treasury engine, customer-held cloud keys, HSM-backed custody, FIPS-204/ML-DSA, sound STARK proofs, regulatory certification, verified savings, or GPU/NVLink performance. Older numerical and assurance claims are withdrawn; see the [claim audit](../claim-audit.md).

## What would be needed before a client proposal

1. A defined, deployable product scope and tested user workflow.
2. Current, reproducible functional and reliability results tied to a release commit.
3. Independent security review, standard cryptographic components, and demonstrated key custody.
4. Verified hosting, data handling, tenant isolation, incident response, and support controls.
5. Workload-specific benchmarks on identified hardware with reproducible baselines.
6. Customer discovery, validated pricing, and substantiated case studies.
7. Legal and compliance review of every external statement.

Until these items are complete, use only an explicitly labeled prototype demonstration, with synthetic data identified as such and no performance, certification, customer, or savings promises.
