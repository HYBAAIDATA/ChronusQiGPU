3. Verify mirror completeness and revoke confirmed exposed credentials.
   Never retain raw secret findings in a public artifact; history removal

   Classify each path; avoid deleting active imports, build inputs, legal

4. Download the current hygiene report from CI (not a truncated log or
   a manually transcribed list). Generate exact candidate paths against the
   scanned tree. Run from a verified local checkout of the report's commit:

```bash
python - artifacts/repo_hygiene_report.json owner-candidate-purge.txt <<'PY'
import json
import pathlib
import re
import subprocess
import sys
report = json.loads(pathlib.Path(sys.argv[1]).read_text(encoding="utf-8"))
head = subprocess.check_output(["git", "rev-parse", "HEAD"], text=True).strip()
if report["commit_sha"] != head or report["violation_count"] != len(report["violations"]):
    raise SystemExit("Report does not match the checked-out source tree")
tracked = set(subprocess.check_output(["git", "ls-files", "-z"]).decode("utf-8").split("\\0")) - {""}
candidates = set()
for finding in report["violations"]:
    path = finding["path"]
    if finding["rule_id"] == "ROOT_DIR_NOT_ALLOWLISTED":
        candidates.update(p for p in tracked if p.startswith(path))
    elif path in tracked:
        candidates.add(path)
    else:
        candidate = re.sub(r":\d+$", "", path)
        if candidate not in tracked:
            raise SystemExit(f"Unresolved finding path: {path}")
        candidates.add(candidate)
if any("\n" in path or "\r" in path or path.startswith(("#", "glob:", "regex:", "literal:")) or "==>" in path for path in candidates):
    raise SystemExit("Ambiguous path requires separate owner review")
pathlib.Path(sys.argv[2]).write_text("".join(p + "\n" for p in sorted(candidates)), encoding="utf-8")
PY
```

   Review every candidate against dependencies, licences, provenance, active
   execution paths and evidence retention. Do not automatically approve the
   candidate list. Create owner-approved-purge.txt containing only approved
   exact paths. Confirm the approved list is a subset of the current candidate
   list, with no pattern directives or rename syntax:
```bash

PY
```

Do not push the rewritten mirror until dependencies, full CI, tag signing,
affected PRs/forks and release evidence have been independently reconciled.
A new public distribution repository is a safer alternative to rewriting an
active repository. No publication, visibility change or force push is
authorised by this runbook.

The path inventory is based on the real Git tree. The full validator is
deliberately strict and may fail existing main; it must not be weakened to
make this branch green. Binary and oversized file content remains outside
the regex scanner and requires independent IP review. GitHub Actions
Gitleaks organisation licensing/secret configuration is an owner dependency.
