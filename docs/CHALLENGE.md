# The Chronus challenge — evidence and disproof conditions

These are **questions to be experimentally tested**, not declarations of demonstrated physical laws.

1. Can a golden-angle *physical* storage layout outperform equal-device baseline packing or access at comparable density, controller policy and failure rate?
2. Does H4-guided search beat exhaustive enumeration in **oracle calls** on target-unknown problems with matching correctness and controls, and does its advantage scale?
3. Can the entire PULVINI representation (active bytes, all kernels, serialization, dtype, metadata, reconstruction) reduce **net** retained storage for named classes of real observed data?
4. Can a reversible computation produce a measured physical reduction in energy for equal useful work after all movement and recovery are included?
5. Can single-erasure recovery restore one missing or altered independently hashed shard, and correctly fail on two missing shards? Tests establish this bounded *software* property, not a power-loss storage guarantee.
6. Can the device survive measured crashes, firmware resets or real power interruption under a published durability fault model and third-party verification?
7. Can exact non-Clifford universal execution be demonstrated independently, instead of inferring quantum speedup from an efficient classical stabilizer method?

Each experiment needs actual source data, input hashes, exact revision, declared hardware/software environment, honest comparator, repeated observations, confidence/error interval where appropriate, raw outputs and verified custody. Missing observations remain UNAVAILABLE. No claim is promoted from this document.
