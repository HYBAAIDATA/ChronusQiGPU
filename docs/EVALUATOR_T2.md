# T2 independent evaluator contract

The production claim **"FIPS 204 ML-DSA signature on every AL HARAS decision — Implemented"** is **HELD**, not verified. Ed25519 RFC 8032 is not FIPS 204. A second ML-DSA-65 signature must cover a domain-separated digest of the message and its Ed25519 signature. Both signatures are required.

The standalone evaluator CLI is `python -m chronus.crypto.verify_bundle --bundle bundle.json --public-keys keys.json`. A bundle must contain `message_hex`, `signatures` with both algorithms in hex, and key identifiers; keys must be supplied independently as `Ed25519` and `ML-DSA-65` public keys in hex. Exit 0 is valid; exit 1 is invalid/unavailable. The verifier does not depend on private keys or repository test fixtures.

No published FIPS 204 vector is asserted until an independent official vector corpus is ingested, verified and retained with digest. The Ed25519 RFC 8032 vector is available in `tests/test_crypto_signers.py`. T2 acceptance requires independent execution and public-key-only validation, not internal pytest alone.

All CI evidence must be generated by Actions, attested to the commit and workflow identity, verified before qualification and retained with an immutable digest. A skipped test or unverified attestation is UNQUALIFIED. The repository must not self-assert that an unsigned local manifest came from Actions.

Azure Managed HSM is the only qualified custody provider under the target policy. Its integration and attestation are outstanding. Local memory and file providers are development-only.

## Implemented evaluator commands

Generate an ephemeral-key **development** fixture set on an ML-DSA-capable stack:

```bash
python scripts/seal_bundle.py --out dist/t2-bundle
python scripts/check_bundle.py dist/t2-bundle --public-keys dist/t2-bundle/public-keys.json
```

The checker verifies the manifest's dual signature, the listed file digests, and three expected outcomes: clean=0, tampered=2, missing ML-DSA=3. These fixture keys are ephemeral; supplying the public keys from the same bundle is **not independent key pinning**. An evaluator must obtain and pin authorized public keys separately, then verify the supplied bundle. A released T2 pack, signed by a stable authorized key and externally reviewed, remains outstanding.

`chronus.journal.Journal` now fsyncs each appended frame; only incomplete terminal writes can be truncated on recovery. `chronus.durable.DurableChain.resume` re-verifies recovered signed receipts before advancing its head. This is not yet THESEUS integration or proof of Japan IDCF replay.

`chronus.gates` now contains five explicit diagnostic gates; claims and custody remain UNQUALIFIED until independent audit and live Managed HSM sign-and-verify evidence. The CI product evaluator continues to hold all product gates; diagnostic PASS is never production PASS.
