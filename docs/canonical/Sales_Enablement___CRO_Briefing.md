You sell **HYBA Data** — **Computational Intelligence as a Service (CIaaS)**, not SaaS.

**Two products (do not collapse):**

- **PULVINI** — memory fold / working-set compression (φ-power `d`)

## 3. Commercial playbook (the 25% rule)

1. **Discover** — memory-bound or GPU-bound workload; name data class (structured numerical, model weights, sensor, other).
2. **Qualify** — eligible set only. Refuse “compress everything.”
3. **Prove** — pilot / local trial on their hardware or agreed representative data (Folding Standard §8).
4. **Measure** — baseline → deploy → m_eff → sealed telemetry path ([HYBA Data — Pilot Measurement Protocol](HYBA%20Data%20%E2%80%94%20Pilot%20Measurement%20Protocol%209c56caf52be040a28f37da830164758e.md)).
5. **Price**

```jsx
Fee = 0.25 × Measured_Savings
Measured_Savings = S_eligible × (1 − 1/m_eff)
Fee = 0 if not measured
```

List wrappers ($/GPU/mo, $/TB) = advance/true-up only — always reconciling to measured gain-share.

## 7. Operating rules (elevation law)

**We do not have overclaims.** Documented doctrine is the bar. Primary move: **elevate code to meet documentation** — or research the gap. Lanes gate readiness, not ambition.

- **Ship with seal:** M1 ~2.62× BOUNDED + method + data class + hash; sensitivity math until production m_eff; fee only on measured savings.
- **In elevation (keep building):** depth-4 / ~85.6% / multi-× GPU / stack multipliers — open the lane when harness + artifact are green; do not water down the target.
- **Competitor figures (CompactifAI etc.):** third-party category proof only — never paste as HYBA seal.
- **Not the Data product:** physical QPU storage, VQC as cold open, mining as Data proof, SaaS seats/maintenance as category.
- **Maturity map:** QML = exploration SOW; QKD = narrow premium; optimisation = feature not platform — elevate each before mass quota.
- Every pack: **HYBA Data lockup** + CoS/CPO gate when it leaves the ecosystem.
- Portfolio SKUs stay on the board; open when metric + pilot path + hash exist.

## 8. Discovery script (10 minutes)

1. Where does memory or GPU capacity constrain roadmap or bill?
2. What is the workload class (training, inference, lake, ticks, sensor)?
3. Can we define an **eligible** subset for a 90-day measured pilot?
4. Who owns FinOps / infra sign-off for gain-share commercial terms?
5. Any air-gap / residency constraint (shapes deploy tier)?
6. (If regulated/gov) Is there a **PQC / harvest-now** budget line separate from infra FinOps?

**Exit:** pilot scope one-pager + sensitivity ROI — not a mega-claim deck.
