**Status: implementation-ready spec.** This is a formal specification for QSDL under the quantum-from-maths paradigm. It replaces physical cavities with manifold faces, weak measurement with direct expectation-value computation, and cryogenic hardware with classical execution. The Python reference implementation is designed to integrate with real HYBA modules: `core/manifold.py` (M32), `quantum/variational.py` (QAOAOptimizer), and `quantum/tensor_train.py` (TensorTrainState/MatrixProductOperator).
## Design principles
1. **Quantum-from-maths:** QSDL describes quantum-mathematical operators, not physical hardware. No cavities, lasers, or cryogenics. The manifold is mathematical.
2. **Substrate-agnostic:** The same QSDL program runs on CPU, GPU, or any future quantum substrate. The compiler targets the available compute.
3. **Manifold-native:** Scene geometry maps to manifold faces (M32 or generalised N-face). Spectral adjacency determines coupling structure. This reuses the real `core/manifold.py` topology.
4. **Composable:** Hamiltonians compose additively. Objects, materials, and lights each contribute terms. The total Hamiltonian is the sum.
5. **Direct readout:** No weak measurement or observer-effect compensation. Expectation values are computed directly: ⟨O⟩ = ⟨ψ\|O\|ψ⟩. This is exact, not approximate.
6. **Tensor-safe:** All state representations support tensor-train decomposition via `quantum/tensor_train.py`. The spec includes reconstruction invariants.
## 1. Grammar (BNF)
```ebnf
/* QSDL Grammar — Quantum Scene Description Language v1.0 */

scene           ::= 'scene' IDENT '{' scene_body '}'
scene_body      ::= [manifold_decl] object_decl* light_decl* camera_decl [quality_decl]

manifold_decl   ::= 'manifold' manifold_type [param_overrides]
manifold_type   ::= 'M32' | 'M64' | 'M128' | 'M256' | 'custom' '(' IDENT ')'
param_overrides ::= '{' param_assign* '}'
param_assign    ::= IDENT '=' value

object_decl     ::= 'object' IDENT '{' object_body '}'
object_body    ::= geometry_decl material_decl transform_decl? [animation_decl]

geometry_decl   ::= 'geometry' geometry_type [geometry_params]
geometry_type   ::= 'sphere' | 'box' | 'plane' | 'mesh' | 'procedural'
geometry_params ::= '(' param_list ')'

material_decl   ::= 'material' IDENT '{' material_body '}'
material_body   ::= property_assign* [quantum_state_decl]
property_assign ::= IDENT '=' value
quantum_state_decl ::= 'quantum' '{' quantum_body '}'
quantum_body    ::= 'hamiltonian' '=' hamiltonian_expr
                   | 'coupling' '=' coupling_expr
                   | 'resonance' '=' value_list

transform_decl  ::= 'transform' '{' transform_op* '}'
transform_op    ::= 'translate' '(' vec3 ')'
                 | 'rotate' '(' vec3 ',' value ')'
                 | 'scale' '(' vec3 ')'

animation_decl  ::= 'animate' '{' animation_body '}'
animation_body  ::= 'property' IDENT 'keyframes' '[' keyframe* ']'
keyframe        ::= '(' value ',' value ')'   /* (time, value) */

light_decl      ::= 'light' IDENT '{' light_body '}'
light_body      ::= 'type' '=' light_type
                   | 'position' '=' vec3
                   | 'intensity' '=' value
                   | 'spectrum' '=' spectrum_expr
                   | 'driving' '=' hamiltonian_expr
light_type      ::= 'point' | 'directional' | 'area' | 'environment'

camera_decl     ::= 'camera' '{' camera_body '}'
camera_body    ::= 'resolution' '=' vec2
                 | 'fov' '=' value
                 | 'position' '=' vec3
                 | 'look_at' '=' vec3
                 | 'up' '=' vec3
                 | 'readout' '=' readout_spec

readout_spec    ::= '{' readout_body '}'
readout_body    ::= 'observables' '=' observable_list
                   | 'supersampling' '=' value
                   | 'tone_map' '=' tone_map_type
observable_list ::= '[' observable* ']'
observable      ::= 'intensity' | 'depth' | 'normal' | 'color' | 'radiance' | custom_observable
custom_observable ::= IDENT '(' param_list ')'

quality_decl    ::= 'quality' '{' quality_body '}'
quality_body    ::= 'evolution_steps' '=' integer
                   | 'layers' '=' integer
                   | 'learning_rate' '=' value
                   | 'damping' '=' value
                   | 'reconstruction_threshold' '=' value
                   | 'seed' '=' integer

/* Value types */
value           ::= NUMBER | IDENT | expression
value_list      ::= '[' value* ']'
vec2            ::= '(' value ',' value ')'
vec3            ::= '(' value ',' value ',' value ')'
param_list      ::= param_pair (',' param_pair)*
param_pair      ::= IDENT '=' value
integer         ::= INTEGER
tone_map_type   ::= 'linear' | 'reinhard' | 'filmic' | 'aces'
```
