Its test helper also strips `+/-` stabilizer signs, so phase errors can be hidden. [[1]](https://github.com/QuantumPhi2/PhiMiner/pull/3)

Correct the public transport object so callers cannot construct contradictory metadata, and distinguish host reference evidence from device-measured evidence. [[3]](https://github.com/QuantumPhi2/PhiMiner/pull/6)
4. **PR #2 is the correct epistemic direction.** `UNTESTED` is not `TESTED_AND_REFUTED`. Before treating it as a release gate, bind each tested disposition to a reproducible artifact, commit, environment, and hash; the current register is mainly static metadata. [[4]](https://github.com/QuantumPhi2/PhiMiner/pull/2)
5. **PR #4 needs a reachability regression test.** The runtime rewrite removes the prior `TRANSFER_VERIFIED` update for retrieved memory. Restore the evidence transition and avoid using a cycle index as a durable event timestamp. [[5]](https://github.com/QuantumPhi2/PhiMiner/pull/4)
6. **PR #1 needs stricter research-run classification.** It distinguishes skipped nodes, but does not treat `xfailed` nodes as non-passing. [[6]](https://github.com/QuantumPhi2/PhiMiner/pull/1)
