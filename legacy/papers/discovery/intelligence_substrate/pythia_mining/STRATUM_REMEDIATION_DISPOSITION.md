# Stratum Handshake → Share-Acceptance Remediation — Defect Disposition Log

**Scope:** `pythia_mining/stratum_client.py` (`StratumClient`), `headless_miner.py` (`state_mine` + telemetry call sites).
**Tests:** `tests/test_stratum_handshake_integrity.py` (in-memory Stratum v1 mock server, same harness pattern as `tests/test_stratum_live_session.py`).
**Status:** All findings remediated; 7/7 regression tests pass; flake8 clean; black clean on `stratum_client.py` + test file (`headless_miner.py` had 3 pre-existing non-clean regions at HEAD, untouched by this change).

| # | Finding | Disposition | Evidence |
|---|---------|-------------|----------|
| M1 | Submit/handshake ID collision surface | **Fixed.** `_listen_loop` now resolves `_pending_futures` before the `req_id == 2` authorize shortcut; pending entries are consumed exactly once (pop on verdict). `_submit_counter` seeded at 10 (above `_SUBMIT_ID_FLOOR = 3`), never reset in `connect()`, and `submit_share` hard-fails with `RuntimeError` if an id would land in `_HANDSHAKE_REQUEST_IDS = {1, 2}`. | `stratum_client.py`: dispatch reorder in `_listen_loop`; guard in `submit_share`. Test: `test_submit_ids_clear_handshake_range_and_survive_reconnect` — wire id ≥ 3, monotonic across a real reconnect, forced counter regression raises and writes nothing. |
| M2 | Late ACKs silently dropped | **Fixed.** On submit timeout the pending record moves to bounded `_late_acks` (grace `HYBA_LATE_ACK_GRACE_SECONDS`, default 60s; cap `_LATE_ACK_MAX_ENTRIES = 128`, expiry-pruned). A matching late response reconciles into `pool_accepted`/`pool_rejected`, increments `late_acks_reconciled`, and emits `share_accepted_late`/`share_rejected_late` (`pool-confirmed-late`/`pool-rejected-late`). Expired or stale-session late verdicts are dropped with a warning. | `stratum_client.py` timeout branch + late-ACK branch in `_listen_loop`. Test: `test_late_ack_reconciles_into_pool_accepted`. |

ACKs whose recorded `session_epoch` mismatches are dropped and the future failed. `headless_miner.state_mine` discards a latched job whose `session_epoch` tag predates the current session. | `stratum_client.py` `_invalidate_session`, `_listen_loop` EOF/error branches, `connect()` post-open hook, session-epoch drop in dispatch. `headless_miner.py` session-epoch guard in `state_mine`. ## Caveats

- **`viabtc_worker.py` is absent from this checkout**, so `stratum_client.py` previously could not be imported standalone. A minimal env-based fallback resolver now sits inside `stratum_client.py` behind the existing double `try/except`; where the real `viabtc_worker` module exists (packaged `python_backend` tree) it is still preferred. Verify against the upstream module's signature (`resolve_viabtc_worker(explicit=...) -> Optional[str]`).
- `headless_miner.py` cannot be imported in this checkout (many `python_backend.*` siblings absent), so its call-site edits were verified by `py_compile` and code review rather than executed tests; the stratum-side epoch/attribution logic they consume is fully covered by the new suite.
- `pool_accepted` and `shares_accepted` aggregate diverge only where firewall/late paths are involved; `get_stats()` exposes all components for reconciliation.
