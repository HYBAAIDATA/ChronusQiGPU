<b>Locked identity:</b> enterprise tensor mathematics and safe tensor artifacts. Canonical spelling: Kellogg. One mathematical authority, not a duplicate hardware scheduler or mining identity.

<b>Status:</b> responsibility baseline documented; executable API/version mapping and current qualification open.

## Owned authority

Complex-preserving TT/MPS decomposition and reconstruction; MPO algebra and contractions; declared numerical error budgets; invariant checks; tensor representation accounting and safe <code>.pv</code> artifact format. Optional domain-specific operators remain capability-scoped, not proof that every solver is qualified.

Chronus owns probing, scheduling, transfers and execution evidence. Ovid/PULVINI folding and Theseus custody are separate responsibilities. Historical Aethel fold-custody references need version/lineage mapping rather than duplication.

## Required technical contract

| Operation family | Required contract |
| --- | --- |
| Decompose / reconstruct | Bind dtype, shape, complex phase, rank/bond limits and requested error budget; report actual error |
| Contract / evolve | Validate compatible dimensions, supported operator/state class and resource limits; preserve declared invariants |
| Serialize / restore | Canonical safe format; schema/version, dtype/shape and integrity binding; atomic replacement where supported; no pickle |
| Authenticate artifacts | Distinguish SHA-256 integrity from optional HMAC authenticity; declare key identity and verification policy |

Historical public namespace is <code>kellogg</code>; the reviewed integration record does not enumerate full current signatures. Operation families above are requirements, not invented callable names or a deployed REST service. Pin exports and schema fixtures before calling the ABI frozen.

## Non-mining acceptance requirement

Reconstruct complex enterprise tensors within a declared error budget; compare contracted operators with an independent bounded reference; reject malformed shape, nonfinite values, corrupted artifacts and invalid authentication. Record logical versus materialised storage honestly. No fresh execution is claimed.

## Mining boundary

A mining consumer may use eligible tensor operations, but Kellogg does not own proof/target semantics, submission or accepted-share truth. Representation compression is not a multiplier for completed hash work.

## Customer schedule

Scope the licensed operations, exactness/approximation policy, supported formats and limits per version. No guaranteed compression ratio, numerical advantage or device throughput without workload-specific evidence. License, fees, support and SLA require an approved product schedule.
