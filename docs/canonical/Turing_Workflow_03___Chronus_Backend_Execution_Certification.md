# Turing Workflow 03 — Chronus Backend Execution Certification

<aside>

Chronus may execute Turing workloads, but Turing remains semantic authority.

</aside>

## Sequence

1. Freeze Turing workload and expected result.
2. Record representation and exactness contract.
3. Capture Chronus backend/device certificate.
4. Execute CPU/reference path.
5. Execute target Chronus backend.
6. Synchronize device work before timing.
7. Compare result/measurement against reference.
8. Record latency, throughput, memory, bytes moved and power/energy when instrumented.
9. Test resource exhaustion, cancellation, timeout and backend disappearance.
10. Bind evidence to Turing package + Chronus package + physical device/runtime versions.

## Rule

Chronus acceleration is not a Turing quantum-advantage claim. Hardware-specific claims require hardware-specific evidence.
