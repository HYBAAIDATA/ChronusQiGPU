# Historical benchmark report — withdrawn

**Disposition: no validated performance result is established by this repository review.** Historical throughput, latency, energy, GPU/NVLink comparison, and hardware advantage claims in this report are withdrawn and must not be repeated as measured product results.

The review at `a2768d11847de113d26535e33cfe9d4a79a009db` did not run benchmarks or validate a physical device. The default CPU reference implementation and opt-in OpenCL adapter do not, by themselves, substantiate accelerator performance.

## Evidence required for a replacement benchmark

A replacement must state the exact source commit, device model and configuration, driver/runtime/compiler, workload and input sizes, warm-up and repetition procedure, baseline implementation, raw measurements, statistical treatment, power measurement method if applicable, and known limitations. Independent reproduction is recommended before external comparison claims.

See the [claim audit](../claim-audit.md). This withdrawal notice is not a benchmark.
