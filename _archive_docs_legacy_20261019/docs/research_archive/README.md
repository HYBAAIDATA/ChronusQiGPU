## Reproduce local integrity verification

```bash
python scripts/verify_euclid_research_archive.py
python -O scripts/verify_euclid_research_archive.py
```

The script validates every page export hash and child closure, decodes and hashes
but **does not extract/execute** the archive, verifies all original manifest
members, and compares review copies. Base64 is transport, not encryption.
The archive includes historical memory and nested ZIPs: do not restore/import
these into the new instance. Review in an offline laboratory before evaluating
any old executable. Retaining a source file is not runtime integration.
