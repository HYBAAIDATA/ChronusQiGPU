## What closes a claim

Bind requirement, precise supported assertion, exact source and version, environment, executed method, retained result/artifact hashes, limitations, reviewer and approval status. Unknown values stay unknown; no fictional reviewer, auto-updated last-verified date or zero-failure count for unrun tests.

## Publication blockers

Named owners, supported-version choice, security/IP review, customer access architecture, source contradictions in custody naming, deployment task screenshots, production math renderer/accessibility audit and required product/service qualification remain open. Documentation coverage does not close these gates.
